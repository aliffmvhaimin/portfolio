Project Brief

One-Line Idea
- A responsive, single-page glassmorphic portfolio showcasing core technical skills, selected projects, and direct contact details.

Real User Moment
- A potential employer or client opens the site after clicking a link in a resume, email, or profile to verify skills and work samples.

Visitor Goal
- Understand my core capabilities, evaluate 2–3 featured projects, and quickly access my email or professional profiles.

Audience
- Hiring managers, technical recruiters, and prospective clients seeking software development skills.

Page / Section Map
- Hero & Knowledge: Brief introduction statement paired with core skill badges.
- Featured Projects: Two to three static project cards displaying summaries and external code links.
- Contact: Final section containing direct email links and professional profile buttons.

Content I Have
- Basic bio text, a list of personal technical skills, and external links to GitHub and LinkedIn.

Content I Will Fake
- Placeholder project images/gradients, template project descriptions, and sample demo links (#).

Core Features
- Glassmorphic CSS layout featuring translucent cards and background blur.
- Interactive hover effects for project cards and navigation elements.
- Direct frontend contact links (mailto: and external profile URLs).

Non-Goals
- Backend form submission handling, database storage, user authentication, or dynamic GitHub API integrations.

Style Feeling
- Modern, translucent, minimal, sleek, dark-toned.

Success Check
- The page renders correctly across devices, all external links work, and the visual glassmorphism effect remains legible and stable.

Cut List
- Live contact form backends, light/dark mode toggles, project detail pop-up modals, database-driven projects, and chat widgets.
