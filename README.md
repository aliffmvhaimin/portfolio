# Portfolio Website

A responsive single-page glassmorphic portfolio created using HTML and Tailwind CSS.

## Features
- **Glassmorphism UI**: Translucent dark cards with backdrop blur, smooth ambient gradients, and crisp borders.
- **Hero Section**: Bio, headline, and core technical skill badges.
- **Featured Projects**: Interactive project cards showcasing recent work and technical highlights.
- **Contact & Socials**: Direct email mailto link, GitHub, and LinkedIn links.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Google Fonts (Inter)

## Local Setup
Simply open `index.html` in any modern browser.
